AVISO DE PRIVACIDAD INTEGRAL

Chocolates Artísticos Sarita
Con colaboración de GamesAlone18 Universe

1. Responsable del tratamiento

Chocolates Artísticos Sarita es responsable del tratamiento de los datos personales que se recaban a través de este sitio web y canales oficiales como WhatsApp e Instagram.

2. Datos personales recabados

Se podrán solicitar datos como: nombre, teléfono, correo electrónico y detalles relacionados con el evento o pedido.

3. Finalidad del tratamiento

Finalidades principales:

  • Cotización de productos personalizados
  • Gestión de pedidos y producción artesanal
  • Comunicación con el cliente
  • Coordinación de entregas

Finalidades secundarias:

  • Mejora del servicio
  • Registro interno de solicitudes
  • Promoción y marketing del negocio

4. Almacenamiento de datos

Los datos pueden almacenarse en herramientas digitales como Google Sheets u otros sistemas de gestión interna.

5. Protección de datos

Se implementan medidas razonables de seguridad para proteger la información contra acceso no autorizado, pérdida o alteración.

6. Transferencia de datos

No se comparten datos personales con terceros, salvo cuando sea necesario para la operación del servicio o cumplimiento del pedido.

7. Derechos del usuario

El usuario puede solicitar acceso, modificación o eliminación de sus datos personales mediante los canales oficiales del negocio.

8. Consentimiento

Al enviar una cotización o solicitud, el usuario acepta el tratamiento de sus datos conforme a este aviso de privacidad.

Este aviso se emite conforme a la Ley Federal de Protección de Datos Personales en Posesión de los Particulares (LFPDPPP).
